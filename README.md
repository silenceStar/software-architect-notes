# 系统架构设计师学习笔记

面向软考高级「系统架构设计师」的 Markdown 学习笔记库，按知识体系整理基础理论、架构设计方法、典型架构实践与论文写作要点。

## 内容概览

- **20 个章节，120 篇笔记**：覆盖考试大纲中的核心知识与常见架构主题。
- **按章节存放**：每个主题下的文件以小节编号命名，便于循序学习与检索。
- **适合复习与查阅**：可按推荐路径系统学习，也可以从下方目录直达目标主题。

## 推荐学习路径

1. 先学习基础：第 1～6 章，建立计算机、信息系统、软件工程、数据库与安全知识框架。
2. 再掌握架构能力：第 7～10 章，聚焦架构风格、质量属性、评估、可靠性与演化。
3. 了解技术趋势：第 11 章，补充 AI、云计算、边缘计算、数字孪生等综合技术。
4. 深入架构实践：第 12～19 章，学习信息系统、分层、云原生、SOA、安全与大数据等架构设计。
5. 最后进行论文训练：第 20 章，结合历年题目练习审题、提纲与写作。
