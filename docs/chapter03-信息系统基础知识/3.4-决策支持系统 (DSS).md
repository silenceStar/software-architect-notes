# 3.4 决策支持系统（DSS）

## 1. 本节核心思想

决策支持系统以数据、模型和方法为主要资源，通过交互式分析、预测、模拟及方案比较，辅助管理者解决半结构化或非结构化决策问题，提高决策的有效性，但不代替管理者作出最终决策。

## 2. 考试高频考点

* **考点1：DSS的核心定位**
  DSS主要面向中高层管理者，支持半结构化和非结构化问题，强调“辅助决策而非代替决策”。

* **考点2：DSS的基本结构**
  经典两库结构由数据库子系统、模型库子系统和对话子系统组成，其中“两库”是指数据库和模型库。

* **易混点：DSS与MIS的区别**
  MIS主要处理结构化问题、提供固定报表并提高管理效率；DSS主要进行预测、模拟和方案比较，重点提高决策的有效性。

* **易考选择题：DSS的典型特征与功能**
  DSS以数据和模型为主要资源，支持“What-if”分析，强调交互性、灵活性和动态性；管理者处于决策核心，系统不能取代人作出决策。

* **补充高频点：DSS的发展过程**
  DSS经历了数据库、模型库和人机交互系统，逐步增加方法库、知识库，并发展为智能DSS、群体DSS和分布式DSS。

* **补充高频点：数据挖掘的四种结果**
  联合用于发现事件之间的关联，定序用于发现事件先后规律，分类是按已有标签分组，聚类是在无标签情况下自动分组。

* **补充高频点：模型建立方法**
  DSS常用的建模方法包括穷枚举法、算法、启发式方法和模拟法，其中启发式方法主要依靠经验规则解决结构化程度较低的问题。

## 3. 记忆口诀

**口诀：两库一对话，数据加模型；半非做辅助，有效不代替；交互能假设，反馈再决策。**

**解释：**

* “两库一对话”：数据库、模型库和对话子系统；
* “数据加模型”：数据和模型是DSS的主要资源；
* “半非做辅助”：主要支持半结构化、非结构化问题；
* “有效不代替”：提高决策有效性，但不代替管理者；
* “交互能假设”：支持人机交互和“What-if”分析；
* “反馈再决策”：决策执行后收集反馈，动态调整方案。

## 4. 考试一句话总结

DSS最可能考查其“两库一对话”结构，以及“以数据和模型辅助半结构化决策、提高决策有效性但不代替人”的核心特点。
