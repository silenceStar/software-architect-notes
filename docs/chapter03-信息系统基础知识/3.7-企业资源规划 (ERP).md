# 3.7 企业资源规划（ERP）

## 1. 本节核心思想（100字以内）

企业资源规划（ERP）是在 MRPⅡ 基础上发展而来的企业资源管理系统，以**物流、资金流、信息流（三流）**为核心，实现企业供应链资源的全面集成管理，为企业提供计划、控制、决策和经营管理支持，提高整体运营效率和竞争力。

---

## 2. 考试高频考点

### 考点1：ERP的概念（★★★★★）

ERP（Enterprise Resource Planning，企业资源规划）是在 **MRPⅡ** 基础上发展而来的管理思想和信息系统。

核心特点：

- 管理对象：**物流、资金流、信息流（三流）**
- 管理范围：**整个供应链**，不仅是企业内部
- 核心目标：资源优化配置，提高企业竞争力

> **ERP 不仅是一套软件，更是一种现代企业管理思想。**

### 考点2：ERP与MRP、MRPⅡ的区别（★★★★★）

发展过程：

```text
MRP → MRPⅡ → ERP
````

* **MRP**：解决"缺什么物料"（物料需求计划）
* **MRPⅡ**：增加生产、财务等资源管理
* **ERP**：扩展到供应链管理，实现企业资源全面集成

记忆：

> **MRP管物料，MRPⅡ管制造，ERP管整个企业和供应链。**

### 考点3：ERP的核心资源（★★★★★）

ERP管理企业三大资源（又称"三流"）：

* **物流**
* **资金流**
* **信息流**

这是历年考试最常考的知识点之一。

### 考点4：ERP主要模块（★★★★☆）

教材共列出11个基本模块，考试重点记住主要模块即可：

* 生产预测
* 销售管理
* 经营计划
* 主生产计划（MPS）
* 物料需求计划（MRP）
* 能力需求计划（CRP）
* 车间作业计划（PAC）
* 采购与库存管理
* 质量与设备管理
* 财务管理
* 扩展模块（CRM、SCM、电子商务等）

其中最常考的是：

**MPS → MRP → CRP → PAC** 的生产计划流程。

### 易混点

**MRP、MRPⅡ、ERP**

| 系统   | 管理范围       |
| ---- | ---------- |
| MRP  | 物料需求       |
| MRPⅡ | 制造资源       |
| ERP  | 企业资源 + 供应链 |

**MPS、MRP、CRP**

* **MPS（主生产计划）**：决定生产什么、生产多少、什么时候交货。
* **MRP（物料需求计划）**：计算需要哪些物料、何时采购或生产。
* **CRP（能力需求计划）**：判断设备、人力等生产能力是否满足需求。

### 易考选择题

* ERP管理企业哪三种资源？（物流、资金流、信息流）
* ERP是在什么基础上发展来的？（MRPⅡ）
* ERP管理范围扩展到哪里？（供应链）
* 主生产计划的英文缩写是什么？（MPS）
* 物料需求计划的英文缩写是什么？（MRP）
* 能力需求计划的英文缩写是什么？（CRP）

## 3. 记忆口诀

### 口诀

**三流一链，三级发展；主物能车，采购财管。**

### 解释

**三流：**

* 物流
* 资金流
* 信息流

**一链：**

* 供应链管理

**三级发展：**

* MRP
* MRPⅡ
* ERP

**计划流程：**

* 主：主生产计划（MPS）
* 物：物料需求计划（MRP）
* 能：能力需求计划（CRP）
* 车：车间作业计划（PAC）
