# 3.1 信息系统概述

## 1. 本节核心思想

信息系统是由人员、硬件、软件、网络、信息资源和规章制度组成的人机系统，其核心是对信息进行输入、存储、处理、输出和控制。本节重点介绍信息系统的发展阶段、系统分类、生命周期、建设原则及常用开发方法。

## 2. 考试高频考点

* **考点1：诺兰模型六阶段**
  信息系统发展依次经历初始、传播、控制、集成、数据管理和成熟六个阶段，其中前三个阶段具有计算机时代特征，后三个阶段具有信息时代特征。

* **考点2：信息系统分类与生命周期**
  传统信息系统主要包括业务处理系统（TPS）、管理信息系统（MIS）、决策支持系统（DSS）、专家系统（ES）和办公自动化系统（OAS）；生命周期分为产生、开发、运行和消亡四个阶段。

* **易混点：系统分析与系统设计**
  系统分析解决“系统要做什么”，形成逻辑模型；系统设计解决“系统怎样实现”，形成具体实施方案。

* **易考选择题：开发方法的适用场景**
  需求明确、业务稳定适合结构化方法；需求不明确、需要反复确认适合原型法；强调对象、类、封装、继承和多态的是面向对象方法；强调接口解耦、复用和互操作的是面向服务方法。

## 3. 记忆口诀

### 口诀

> 五能“输存处出控”，
> 六段“初传控集数成”；
> 五类“事管决专办”，
> 四期“产生开发运行亡”；
> 开发“规分设实验”，
> 原则“高用顶工”，方法“结构原型对象服务”。

### 解释

* **输存处出控**：输入、存储、处理、输出、控制。
* **初传控集数成**：初始、传播、控制、集成、数据管理、成熟。
* **事管决专办**：业务处理系统、管理信息系统、决策支持系统、专家系统、办公自动化系统。
* **产生开发运行亡**：产生阶段、开发阶段、运行阶段、消亡阶段。
* **规分设实验**：总体规划、系统分析、系统设计、系统实施、系统验收。
* **高用顶工**：高层管理人员介入、用户参与、自顶向下规划、工程化。
* **结构原型对象服务**：结构化方法、原型法、面向对象方法、面向服务方法。

## 4. 考试一句话总结

本节最可能考诺兰模型六阶段、信息系统分类、生命周期顺序，以及不同开发方法的特点和适用场景。
