# 3.6 办公自动化系统（OAS）

## 1. 本节核心思想（100字以内）

办公自动化系统（OAS）是利用计算机、通信和办公设备，实现文字、数据、语音、图像等办公信息的一体化处理，提高办公效率和办公质量的信息系统，是企业日常办公的重要支撑系统。

---

## 2. 考试高频考点

### 考点1：OAS的概念（★★★★★）

OAS（Office Automation System，办公自动化系统）主要解决办公信息处理自动化问题，处理对象不仅包括**数据**，还包括**文字、语音、图形、图像**等多媒体信息。

> **区别于TPS、MIS：OAS侧重办公协同，TPS侧重业务处理，MIS侧重管理分析。**

### 考点2：OAS的三大功能（★★★★★）

1. **事务处理**：文字处理、电子邮件、电子会议、文档管理、报表处理、日程安排等。
2. **信息管理**：信息收集、加工、存储、传递、共享和反馈。
3. **辅助决策**：利用办公信息进行分析、预测，为管理层提供决策支持。

> 功能层次可理解为：**基层办事务，中层管信息，高层做决策。**

### 考点3：OAS的组成（★★★★☆）

办公自动化系统由四部分组成：

- **计算机设备**（服务器、终端、打印机等）
- **办公设备**（电话、传真机、复印机、投影仪等）
- **数据通信及网络设备**
- **软件系统**（系统软件、专用软件、支持软件）

其中软件系统包括：

- 系统软件（操作系统、网络系统）
- 专用软件（办公业务系统）
- 支持软件（Office、数据库、邮件系统等）

### 易混点

**OAS、TPS、MIS、DSS、ES 对比**

| 系统 | 核心作用 |
|------|----------|
| TPS | 处理日常业务数据 |
| MIS | 为管理提供统计分析 |
| DSS | 辅助管理者决策 |
| ES | 利用专家知识进行推理 |
| **OAS** | 支持日常办公协同，提高办公效率 |

### 易考选择题

- OAS主要处理哪些类型的信息？（数据、文字、语音、图形、图像）
- OAS的三大功能是什么？（事务处理、信息管理、辅助决策）
- OAS由哪四部分组成？
- 电子邮件、电子会议属于哪类功能？（事务处理）

## 3. 记忆口诀

### 口诀

**办公三功能：事务、管理、决策；组成四件套：机、办、网、软。**

### 解释

**三大功能：**

- 事务处理
- 信息管理
- 辅助决策

**四大组成：**

- **机**：计算机设备
- **办**：办公设备
- **网**：数据通信及网络设备
- **软**：软件系统
