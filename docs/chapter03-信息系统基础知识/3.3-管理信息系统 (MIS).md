
# 3.3 管理信息系统（MIS）

## 1. 本节核心思想

管理信息系统（MIS）是在TPS基础上发展起来的集成人机系统，通过共享和加工企业内外部数据，为各层管理者提供信息查询、分析、预测、计划、控制和辅助决策等功能，从而提高企业整体管理效能。

## 2. 考试高频考点

- **考点1：MIS的四大组成**  
  MIS由信息源、信息处理器、信息用户和信息管理者组成，可记为“源、处、用、管”。

- **考点2：MIS的层次结构**  
  MIS通常呈金字塔结构，自下而上依次为业务处理、运行控制、管理控制和战略计划；越往下业务量越大，越往上信息越综合、决策性越强。

- **易混点：开环、闭环及纵横综合**  
  开环系统在决策执行过程中不根据反馈调整，闭环系统会不断收集反馈并修正决策；横向综合是按管理层次划分，纵向综合是按销售、生产、人事等职能条线划分，纵横综合则可跨层次、跨职能灵活组合。

- **易考选择题：MIS与TPS的区别及主要功能**  
  TPS主要处理日常业务并产生基础数据，MIS在TPS数据基础上进行综合分析，为管理者提供计划、控制、预测和辅助决策；MIS强调“辅助决策”，通常不代替管理者直接作出最终决策。
