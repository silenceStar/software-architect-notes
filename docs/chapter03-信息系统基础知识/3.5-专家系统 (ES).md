# 3.5 专家系统（ES）

## 1. 本节核心思想（100字以内）

专家系统（ES）是人工智能（AI）的重要分支，以**知识库**和**推理机**为核心，利用领域专家知识和推理规则，模拟专家解决问题的思维过程，适用于医疗诊断、故障检测、规划设计、决策支持等特定领域。

---

## 2. 考试高频考点

### 考点1：专家系统与传统程序区别

- 专家系统：知识 + 推理 = 系统
- 传统程序：数据结构 + 算法 = 程序
- 专家系统模拟的是**专家推理过程**，而不是问题本身。

### 考点2：专家系统组成（★★★★★）

六大组成：

- 知识库（核心）
- 综合数据库（动态知识库）
- 推理机（核心）
- 知识获取
- 解释程序
- 人机接口

其中**知识库 + 推理机**是专家系统的核心。

### 考点3：三种推理方式（★★★★★）

- 正向推理（数据驱动）：条件 → 结论
- 反向推理（目标驱动）：结论 → 条件
- 双向推理：正向 + 反向结合

考试经常考判断题。

### 易混点

**知识库 vs 综合数据库**

- 知识库：长期保存专家知识（静态）
- 综合数据库：保存本次推理产生的数据（动态）

**正向推理 vs 反向推理**

- 正向：已知条件推出结论
- 反向：先假设结论，再验证条件

### 易考选择题

- 专家系统的核心是什么？（知识库+推理机）
- 综合数据库属于静态还是动态知识库？（动态）
- 正向推理属于数据驱动还是目标驱动？（数据驱动）
- 反向推理适用于哪类问题？（目标解空间较小）

## 3. 记忆口诀

### 口诀

**知综推获解人，条件推结论，目标查条件。**

### 解释

- 知：知识库
- 综：综合数据库
- 推：推理机
- 获：知识获取
- 解：解释程序
- 人：人机接口

推理方式：

- 正向：条件 → 结论
- 反向：结论 → 条件
