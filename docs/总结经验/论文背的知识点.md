软件架构设计与分布式集成
最高优先级

对应：微服务、SOA、事件驱动、企业集成、负载均衡、Serverless、云原生。
需要掌握：
- 架构风格的特点、适用场景、优缺点。
- 系统如何分层、模块如何划分、模块之间如何通信。
- 同步调用与异步消息的区别，接口和消息如何解耦。
- 服务注册发现、负载均衡、服务治理、容错与降级。
- 如何根据业务需求选择架构，而不是为了使用某项技术而使用。
你的项目怎么用： 广告平台、网吧服务端和客户端的边界，广告策略接口，离线与实时计算模块之间的协作，都能作为案例素材。
历年覆盖：2021 年微服务与企业集成、2024 年面向服务架构、2025 年事件驱动与负载均衡等。


数据架构与数据处理
最高优先级

对应：数据分片、Lambda、湖仓一体、多源数据集成、多模型数据管理、云原生数据库。
需要掌握：
- Lambda 与 Kappa 架构的区别和适用场景。
- 批处理与流处理的职责划分、数据延迟、结果一致性。
- 数据分片策略、数据倾斜、扩容和热点问题。
- 多源异构数据的采集、转换、整合与质量治理。
- 数据存储选型、缓存、数据模型和读写性能优化。
- 数据重复、迟到、乱序、更新及重算等问题的处理。
你的项目怎么用： Spark 离线计算、Flink 实时处理、用户特征治理、CTR 模型训练、Redis 结果服务。这是你已有知识最深、最容易写出具体实施细节的方向。
历年覆盖：2020 年数据分片、2022 年湖仓一体、2024 年 Lambda、2025 年多模型数据管理等。

对应：软件架构评估、可靠性评估、性能、可用性、可维护性、安全性。

- 单点故障、缓存失效、服务超时、降级和恢复。
- 如何将抽象质量目标转化为可验证的场景和指标。
