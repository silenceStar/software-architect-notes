什么是微服务？微服务有哪些特点和优缺点？

微服务是一种架构模式，将单一应用划分为一组围绕业务构建的小型服务，各服务运行在独立进程中，通过轻量级通信机制（如HTTP/RESTful API）进行协作，并可独立部署。

                 微服务
                   │
       ┌───────────┴───────────┐
       ↓                       ↓
      特点                     价值
       │                       │
   小、细、专、轻、松、独       │
                               │
                   ┌───────────┴──────────┐
                   ↓                      ↓
                  优点                    缺点
                   │                      │
               弹性/扩展                分布式复杂
               技术异构                 运维复杂
               独立部署                 测试困难
               服务组合                 依赖管理
               组织匹配

其特点：
    可概括为“小、细、专、轻、松、独”，
    即粒度小、职责专一、通信轻量、服务松耦合且可独立部署。
其优势：
    包括技术异构、独立扩展、弹性伸缩、独立部署和服务组合等；
缺点：
    包括分布式系统复杂度增加、网络通信开销和故障风险增加、运维及部署成本提高，以及服务间依赖导致测试和管理更加困难。
