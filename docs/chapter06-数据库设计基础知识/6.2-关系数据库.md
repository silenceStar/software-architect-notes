# 6.2 关系数据库

## 1. 本节核心思想（100字以内）

关系数据库以二维表表示数据，关系模型由数据结构、关系运算和完整性约束组成。数据库设计通过函数依赖和规范化减少数据冗余，避免插入、删除和修改异常，并保证数据正确、一致。:contentReference[oaicite:0]{index=0}

## 2. 考试高频考点

- **考点1：关系模型基本概念**  
  行称为元组，列称为属性，属性取值范围称为域；候选码能唯一标识元组，主码是选定的候选码，外码用于引用其他关系的主码。:contentReference[oaicite:1]{index=1}

- **考点2：关系运算**  
  选择是选行，投影是选列；连接用于组合两个关系，自然连接是特殊的等值连接，会去掉重复属性列；除法通常表示“满足全部条件”。:contentReference[oaicite:2]{index=2} :contentReference[oaicite:3]{index=3}
| 运算       | 符号 | 关键词      | 人话          |
| -------- | -- | -------- | ----------- |
| **选择**   | σ  | **筛行**   | 我要哪些记录？     |
| **投影**   | π  | **筛列**   | 我要哪些属性？     |
| **连接**   | ⋈  | **拼表**   | 两张表怎么合起来？   |
| **笛卡尔积** | ×  | **全组合**  | 每行和另一表每行都组合 |
| **并**    | ∪  | **合并**   | A和B都要       |
| **差**    | −  | **排除**   | A有、B没有      |
| **交**    | ∩  | **共同**   | A和B都有       |
| **除**    | ÷  | **全部满足** | 满足所有条件      |


| 关系运算     |  符号 | 动作关键词      | SQL关键词                | 直觉       |
| -------- | --: | ---------- | --------------------- | -------- |
| **选择**   |   σ | **筛行**     | `WHERE`               | 哪些行要？    |
| **投影**   |   π | **筛列**     | `SELECT`              | 哪些列要？    |
| **连接**   |   ⋈ | **拼表**     | `JOIN`                | 两张表关联    |
| **等值连接** | ⋈条件 | **按相等拼**   | `INNER JOIN ... ON =` | ID相等就拼   |
| **自然连接** |   ⋈ | **同名列自动拼** | `NATURAL JOIN`        | 同名属性匹配   |
| **笛卡尔积** |   × | **全组合**    | `CROSS JOIN`          | 每行 × 每行  |
| **并**    |   ∪ | **合并**     | `UNION`               | A或B      |
| **交**    |   ∩ | **取共同**    | `INTERSECT`           | A且B      |
| **差**    |   − | **排除**     | `EXCEPT` / `MINUS`    | A有B没有    |
| **除**    |   ÷ | **全部满足**   | 无直接对应                 | “所有/每一个” |




- **考点3：完整性约束**  
  实体完整性要求主码唯一且非空；参照完整性要求外码取空值或等于被引用关系中的某个主码值；用户定义完整性体现具体业务规则。:contentReference[oaicite:4]{index=4}

- **考点4：函数依赖与范式**  
  2NF消除非主属性对码的部分依赖，3NF消除非主属性对码的传递依赖，BCNF要求函数依赖的决定因素必须包含码，4NF进一步消除不合理的多值依赖。:contentReference[oaicite:5]{index=5} :contentReference[oaicite:6]{index=6}

- **易混点**  
  候选码可能有多个，主码只能从候选码中选定；主属性是包含在任一候选码中的属性。选择是“选行”，投影是“选列”；等值连接保留重复连接列，自然连接删除重复属性列。

- **易考选择题**  
  5种基本关系代数运算是并、差、笛卡尔积、选择和投影；交、连接等运算可以由基本运算导出。范式等级通常为：1NF → 2NF → 3NF → BCNF → 4NF → 5NF。:contentReference[oaicite:7]{index=7} :contentReference[oaicite:8]{index=8}

## 3. 记忆口诀

**口诀：**

> 行元组，列属性，取值范围叫作域；  
> 候选唯一，主码选一，外码引用别关系；  
> 选择选行，投影选列，自然连接重复省略；  
> 一范不可分，二范去部分，三范去传递，BCNF决定因素必须是码，四范去多值。

**解释：**

- 1NF：每个属性值必须是不可再分的原子值。
- 2NF：在1NF基础上，消除非主属性对联合码的部分依赖。
- 3NF：在2NF基础上，消除非主属性对码的传递依赖。
- BCNF：每个非平凡函数依赖的决定因素都必须包含候选码。
- 4NF：消除非平凡且决定因素不包含码的多值依赖。

| 范式       | 消除的问题    | 典型特征        | 看到什么就警觉                |
| -------- | -------- | ----------- | ---------------------- |
| **1NF**  | 非原子属性    | 一个字段多个值     | `{A,B,C}`              |
| **2NF**  | **部分依赖** | 非主属性依赖主键一部分 | `(A,B) → C`，同时 `A → C` |
| **3NF**  | **传递依赖** | 非主属性依赖非主属性  | `A → B → C`            |
| **BCNF** | 不合格的决定因素 | 决定因素必须是超键   | `A → B`，但 A 不是超键       |
| **4NF**  | **多值依赖** | 两组独立的一对多    | `A →→ B`               |
| **5NF**  | **连接依赖** | 关系可以进一步无损分解 | 多表组合关系                 |
