| 对比维度  | 关系数据库                   | 文档数据库                                  |
| ----- | ----------------------- | -------------------------------------- |
| 数据模型  | 关系模型     | 文档模型          |
| 读写性能  | 多表关联、复杂查询时可能产生较多开销      | 对聚合在一个文档中的数据读写效率较高，适合大量简单读写            |
| 模式扩展性 | Schema较固定，增加字段通常需要修改表结构 | Schema灵活，同一集合中的文档可以具有不同字段，扩展方便         |
| 数据一致性 | 强一致性较成熟，支持ACID事务        | 传统上强调灵活性和可扩展性，一致性模型相对灵活；现代MongoDB也支持事务 |
| 适用场景  | 结构稳定、关联关系复杂、事务要求高       | 数据结构变化频繁、半结构化数据、需要水平扩展的场景              |


JSON
 │
 ├── 存储
 │    ├─ 简洁
 │    ├─ 数据类型丰富
 │    ├─ 结构灵活
 │    └─ 空值/可选字段
 │
 ├── 修改
 │    ├─ 文本格式
 │    ├─ 易解析
 │    └─ 易查看、编辑、调试
 │
 └── 传输
      ├─ 格式紧凑
      ├─ 轻量
      └─ 跨平台、跨语言
