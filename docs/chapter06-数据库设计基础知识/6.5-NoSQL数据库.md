# 1. 本节核心思想（100字以内）

NoSQL（Not Only SQL）是一类**非关系型数据库**，不强调传统关系数据库的 ACID 特性，而强调**高性能、高扩展、高可用和灵活的数据模型**，适用于海量数据、高并发和分布式场景。

| 字母 | 英文          | 中文      | 一句话理解         |
| -- | ----------- | ------- | ------------- |
| A  | Atomicity   | **原子性** | 要么全部成功，要么全部失败 |
| C  | Consistency | **一致性** | 数据始终保持正确状态    |
| I  | Isolation   | **隔离性** | 多个事务互不干扰      |
| D  | Durability  | **持久性** | 提交后永久保存，不会丢失  |

# 2. 考试高频考点

## 考点1：NoSQL 四大类型（★★★★★）

```text
                NoSQL
                  │
     ┌──────┬──────┬──────┬──────┐
     │      │      │      │
     ▼      ▼      ▼      ▼
   列式    键值    文档    图数据库
```

| 类型 | 数据模型 | 代表产品 | 典型场景 |
|------|---------|---------|---------|
| 列式数据库 | 按列存储 | HBase、Cassandra | 大数据分析、海量存储 |
| 键值数据库 | Key-Value | Redis | 缓存、Session |
| 文档数据库 | JSON/XML 文档 | MongoDB、CouchDB | 网站、内容管理 |
| 图数据库 | 图结构 | Neo4j | 社交网络、知识图谱 |

**考试重点：数据库类型与代表产品对应关系。**

---

## 考点2：NoSQL 的四大特点（★★★★★）

教材总结如下：

- **易扩展**：天然支持水平扩展，适合分布式部署。
- **高性能**：读写速度快，适合高并发、大数据场景。
- **数据模型灵活**：无需固定表结构，可动态增加字段。
- **高可用**：支持副本、集群和故障切换。

记忆顺序：

> **扩展 → 性能 → 灵活 → 高可用**

---

## 易混点（★★★★★）

### NoSQL 与关系数据库

| 对比项 | 关系数据库 | NoSQL |
|---------|-----------|--------|
| 数据模型 | 表（二维表） | 键值、列、文档、图 |
| Schema | 固定 | 灵活 |
| 事务 | 强调 ACID | 一般不强调 ACID |
| 扩展方式 | 垂直扩展 | 水平扩展 |
| SQL | 标准 SQL | 通常无统一 SQL |

一句话：

> **关系数据库重一致性；NoSQL 重性能和扩展性。**

---

### 键值数据库 vs 文档数据库

**键值数据库（Redis）**

```text
Key
 │
Value
```

特点：

- 查询速度最快
- 一般整体读取 Value
- 适合缓存

---

**文档数据库（MongoDB）**

```json
{
  "name":"Tom",
  "age":18,
  "city":"杭州"
}
```

特点：

- 文档通常采用 JSON 格式
- 支持嵌套结构
- 可以查询文档内部字段

---

### 行式数据库 vs 列式数据库

**关系数据库（按行存储）**

```text
Tom 18 6000
Lucy20 7000
```

**列式数据库（按列存储）**

```text
姓名：
Tom
Lucy

工资：
6000
7000
```

一句话：

> **关系数据库按行存储，HBase 等列式数据库按列存储。**

# 3. 记忆口诀

**口诀：**

> **键值 Redis，文档 Mongo；列式 HBase，图用 Neo；扩展强、性能高、模型活、高可用。**

**解释：**

- **Redis**：键值数据库，缓存首选。
- **MongoDB**：文档数据库，存储 JSON 数据。
- **HBase**：列式数据库，适合海量数据分析。
- **Neo4j**：图数据库，适合关系分析。
- NoSQL 四大特点：**高扩展、高性能、模型灵活、高可用**。

# 4. 考试一句话总结（精简）

**重点掌握 NoSQL 四种数据库类型（键值、列式、文档、图）、代表产品（Redis、HBase、MongoDB、Neo4j）及其特点，并理解 NoSQL 强调高性能、高扩展，而关系数据库强调 ACID 一致性。**
