# 6.4 应用程序与数据库的交互

> **是否需要画图：✅需要**
>
> 本节最大的考点就是**数据库访问方式的区别**，画图最容易理解。

---

# 1. 本节核心思想（100字以内）

应用程序不能直接访问数据库，而是需要通过数据库访问接口进行交互。常见方式包括**库函数（OCI）**、**嵌入式SQL**、**通用接口（ODBC/JDBC）**和**ORM框架**，它们的发展趋势是**越来越通用、越来越易开发、数据库依赖越来越弱**。

---

# 2. 考试高频考点

## 考点1：四种数据库访问方式（★★★★★）

```text
应用程序
    │
    ▼
┌──────────────┐
│ 库函数（OCI）│ ← 数据库厂商专用
└──────────────┘
        │
        ▼
┌──────────────┐
│ 嵌入式SQL     │ ← SQL写进C/Java等语言
└──────────────┘
        │
        ▼
┌──────────────┐
│ ODBC/JDBC    │ ← 统一接口，支持多数据库
└──────────────┘
        │
        ▼
┌──────────────┐
│ ORM框架      │ ← 面向对象开发
└──────────────┘
```

特点总结：

|方式|特点|数据库耦合|
|---|---|---|
|OCI|性能高、底层API|★★★★★|
|嵌入式SQL|SQL写进程序|★★★★☆|
|ODBC/JDBC|统一接口|★★☆☆☆|
|ORM|操作对象，不写SQL|★☆☆☆☆|

**一句话：越来越高级，开发越来越简单。**

---

## 考点2：ODBC 与 JDBC（★★★★★）

这是最喜欢出的选择题。

### ODBC

- Microsoft提出
- C/C++等语言常用
- 统一访问各种数据库
- 依赖ODBC驱动

流程：

```text
应用程序
      │
SQL语句
      │
      ▼
 ODBC接口
      │
      ▼
ODBC驱动
      │
      ▼
Oracle / MySQL / SQL Server
```

特点：

- 统一访问各种数据库
- 与数据库无关
- 靠驱动适配不同数据库

---

### JDBC

Java专用数据库接口。

流程：

```text
Java程序
      │
 JDBC API
      │
 JDBC Driver
      │
 Oracle/MySQL
```

特点：

- Java官方标准
- Java访问数据库几乎都用JDBC
- 和ODBC思想一致，只是语言不同

---

## 考点3：ORM（★★★★★）

ORM（Object Relational Mapping）

中文：

> **对象关系映射**

思想：

程序员操作对象，而不是SQL。

例如：

数据库：

```text
student

id
name
age
```

Java：

```java
Student s = new Student();
s.setName("Tom");
```

ORM自动生成：

```sql
insert into student(name)
values('Tom');
```

程序员：

> 不需要写SQL。

ORM负责：

> 自动转换。

---

常见ORM框架：

|框架|特点|
|------|------|
|Hibernate|全自动|
|MyBatis|半自动，需要写SQL|
|JPA|Java官方标准|

考试经常考：

> **Hibernate：全自动**

> **MyBatis：半自动**

---

## 易混点（★★★★★）

### OCI vs ODBC

OCI：

- Oracle自己的接口
- 性能高
- 强依赖Oracle

ODBC：

- 微软提出
- 统一访问各种数据库
- 与数据库无关

口诀：

> **OCI专一，ODBC统一。**

---

### JDBC vs ODBC

JDBC：

- Java

ODBC：

- 通用接口

一句话：

> **Java用JDBC，其它语言多用ODBC。**

---

### Hibernate vs MyBatis

Hibernate：

几乎不用写SQL。

MyBatis：

SQL自己写。

一句话：

> Hibernate全自动，MyBatis半自动。

# 3. 记忆口诀

**口诀：**

> **库函数最底层，嵌SQL写程序；ODBC做统一，JDBC给Java；ORM管对象，Hibernate全自动，MyBatis半自动。**

**解释：**

- 库函数（OCI）→ 数据库专用API
- 嵌入SQL→ SQL写进程序
- ODBC→ 通用数据库接口
- JDBC→ Java数据库接口
- ORM→ 面向对象开发
- Hibernate→ 全自动ORM
- MyBatis→ 半自动ORM

---

# 4. 考试一句话总结（精简）

**牢记四种数据库访问方式及其特点：OCI（厂商专用）→ 嵌入式SQL → ODBC/JDBC（统一接口）→ ORM（对象映射），重点区分 ODBC 与 JDBC、Hibernate 与 MyBatis。**
