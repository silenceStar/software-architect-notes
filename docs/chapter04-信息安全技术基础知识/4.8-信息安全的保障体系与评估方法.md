# 4.8 信息安全的保障体系与评估方法

## 1. 本节核心思想（100字以内）

信息安全保障既要按照安全等级实施分级保护，也要通过风险评估识别资产、威胁和脆弱性，计算风险并采取安全措施。安全措施只能降低风险，不能完全消除风险，实施后仍需持续监控残余风险。

## 2. 考试高频考点

- **考点1：计算机信息系统安全保护等级**  
  安全保护共分5级：用户自主保护级、系统审计保护级、安全标记保护级、结构化保护级和访问验证保护级，安全能力和抗渗透能力逐级增强。

- **考点2：风险评估基本要素与计算过程**  
  风险评估围绕资产、威胁、脆弱性、风险和安全措施展开，先识别并赋值资产、威胁和脆弱性，再计算安全事件发生可能性和最终风险值。

- **易混点：威胁、脆弱性与风险**  
  威胁是可能造成损害的因素，脆弱性是资产自身存在的弱点；威胁利用脆弱性危害资产才形成风险，脆弱性本身不会直接造成损失。

- **易考选择题：安全等级、自评估和他评估、残余风险**  
  第2级突出安全审计，第3级引入安全标记和强制访问控制，第4级关注结构化设计和隐蔽通道，第5级强调访问监控器；自评估由系统拥有者组织，他评估通常由主管机关发起；采取安全措施后仍会存在残余风险。

## 3. 记忆口诀

**自主审计标结构，访问验证最高级；资产威胁加脆弱，措施降低留残余。**

解释：

- **自主**：第1级用户自主保护级，主要实施自主访问控制。
- **审计**：第2级系统审计保护级，增加登录、审计和责任追踪。
- **标**：第3级安全标记保护级，引入安全标记和强制访问控制。
- **结构**：第4级结构化保护级，强调形式化安全模型、结构化设计和隐蔽通道。
- **访问验证**：第5级访问验证保护级，以抗篡改的访问监控器仲裁全部访问。
- **资产、威胁、脆弱性**：威胁利用脆弱性危害资产，形成安全风险。
- **留残余**：安全措施只能降低风险，不能保证风险降为零。

## 4. 考试一句话总结（精简）

本节最可能考五级安全保护的名称和特征，以及“威胁利用脆弱性危害资产形成风险”的风险评估关系。
