# 4.7 信息安全的抗攻击技术

## 1. 本节核心思想（100字以内）

抗攻击技术通过强化密钥、识别和防御拒绝服务与欺骗攻击、检测端口及系统漏洞，降低系统被入侵或服务中断的风险。重点是理解各种攻击利用了什么机制，以及相应的检测和防御方法。

## 2. 考试高频考点

- **考点1：常见攻击原理**  
  DoS/DDoS通过耗尽网络或系统资源使合法用户无法获得服务；ARP、DNS、IP欺骗分别伪造MAC映射、域名解析结果和源IP地址。

- **考点2：扫描与防御技术**  
  端口扫描用于识别开放端口、运行服务和操作系统；漏洞扫描分为基于网络和基于主机两类，后者通常需要安装Agent，检测更深入。

- **易混点：DoS与DDoS、端口扫描与漏洞扫描**  
  DoS通常由单一攻击源发起，DDoS利用大量受控主机协同攻击；端口扫描主要收集服务信息，漏洞扫描进一步判断系统是否存在可被利用的安全缺陷。

- **易考选择题：SYN Flood与各种扫描方式**  
  SYN Flood利用TCP三次握手未完成，占满服务器半连接队列；全连接扫描完成三次握手，SYN扫描只建立半连接，FIN扫描更隐蔽，第三方扫描利用代理主机实施。

## 3. 记忆口诀

**密钥长强随机，拒服单分要分清；ARP骗MAC，DNS骗IP，SYN占半连，主机扫描装代理。**

解释：

- **长强随机**：密钥应扩大密钥空间、选择强钥并保证随机性和不可预测性。
- **拒服单分**：DoS多为单一来源，DDoS为分布式协同攻击。
- **ARP骗MAC**：篡改IP与MAC地址的对应关系。
- **DNS骗IP**：将域名解析到攻击者指定的虚假IP地址。
- **SYN占半连**：SYN Flood通过大量未完成的TCP连接耗尽服务器资源。
- **主机扫描装代理**：基于主机的漏洞扫描通常需要在目标系统安装Agent。

## 4. 考试一句话总结（精简）

本节最可能考各种攻击的基本原理、攻击之间的区别，以及对应的扫描和防御措施。
