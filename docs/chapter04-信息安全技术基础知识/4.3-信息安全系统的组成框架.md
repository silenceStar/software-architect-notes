# 4.3 信息安全系统的组成框架

## 1. 本节核心思想（100字以内）

信息系统安全不是单纯依靠技术实现，而是由**技术体系、组织机构体系、管理体系**三部分共同构成，即"技术防护、组织保障、管理落实"三位一体，共同保障信息系统安全。

---

## 2. 考试高频考点

### 考点1：信息安全系统三大组成（★★★★★）

信息安全系统框架包括三大体系：

- **技术体系**：提供安全防护能力。
- **组织机构体系**：提供组织保障。
- **管理体系**：提供制度和管理保障。

> **三者缺一不可，其中管理体系最容易考。**

### 考点2：技术体系（★★★★★）

技术体系主要包括五个方面：

1. **基础安全设备**（密码芯片、身份识别卡等）
2. **网络安全**（防火墙、VPN、数字签名、安全审计等）
3. **操作系统安全**（身份认证、访问控制、最小权限、安全审计等）
4. **数据库安全**（访问控制、身份认证、完整性、多级保护等）
5. **终端安全设备**（电话密码机、传真密码机等）

考试重点掌握各层安全对象：

- 网络安全——保护网络传输
- 操作系统安全——保护系统资源
- 数据库安全——保护数据
- 终端安全——保护终端设备

### 考点3：组织机构体系（★★★★☆）

组织机构体系由三个部分组成：

- **机构**
- **岗位**
- **人事**

其中机构分为三个层次：

- 决策层
- 管理层
- 执行层

### 考点4：管理体系（★★★★★）

管理体系包括三个方面：

- **法律管理**
- **制度管理**
- **培训管理**

教材强调：

> **三分技术，七分管理。**

这是考试非常喜欢考的一句话。

---

### 易混点

#### 三大体系

| 体系 | 作用 |
|------|------|
| 技术体系 | 提供安全技术防护 |
| 组织机构体系 | 提供组织保障 |
| 管理体系 | 提供制度、法律和培训保障 |

#### 技术体系与管理体系

- **技术体系**：解决"如何防护"。
- **管理体系**：解决"如何规范"。

---

### 易考选择题

- 信息安全系统框架由哪三个体系组成？
- 技术体系包括哪些主要内容？
- 组织机构体系包括哪些组成？
- 管理体系包括哪三个方面？
- "三分技术，七分管理"强调什么？（管理的重要性）

## 3. 记忆口诀

### 口诀

**技、组、管；五技三组三管。**

### 解释

**三大体系：**

- 技术体系
- 组织机构体系
- 管理体系

**技术五部分：**

- 基础安全设备
- 网络安全
- 操作系统安全
- 数据库安全
- 终端安全

**组织三部分：**

- 机构
- 岗位
- 人事

**管理三部分：**

- 法律
- 制度
- 培训
