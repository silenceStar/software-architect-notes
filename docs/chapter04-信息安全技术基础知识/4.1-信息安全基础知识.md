# 4.1 信息安全基础知识

## 1. 本节核心思想

信息安全通过身份认证、访问控制、加密、审计和安全防护等措施，保障信息系统的机密性、完整性、可用性、可控性和可审查性，防止信息泄露、篡改、服务中断和非法访问。

## 2. 考试高频考点

### 考点1：信息安全五要素（★★★★★）

- 机密性：未授权者不能获取信息。
- 完整性：信息不能被非法修改，并能发现篡改。
- 可用性：授权用户需要时能够正常使用。
- 可控性：能够控制信息的流向和使用方式。
- 可审查性：安全事件发生后能够追踪和调查。

其中最核心的是 CIA：

> 机密性、完整性、可用性。

### 考点2：信息安全的范围（★★★★☆）

信息安全包括：

- 设备安全
- 数据安全
- 内容安全
- 行为安全

数据安全主要强调秘密性、完整性和可用性；内容安全强调合法合规；行为安全强调系统行为过程和结果可控。

### 考点3：认证、访问控制与审计（★★★★★）

- 身份认证：确认“你是谁”，是访问控制的基础。
- 访问控制：决定“你能做什么”。
- 安全审计：记录并追查“你做了什么”。

存取控制主要包括隔离控制和限制权限两种方法。

### 考点4：网络安全五类威胁（★★★★★）

1. 非授权访问
2. 信息泄露或丢失
3. 破坏数据完整性
4. 拒绝服务攻击
5. 利用网络传播病毒

对应关系：

- 信息泄露 → 破坏机密性
- 数据篡改 → 破坏完整性
- 拒绝服务 → 破坏可用性

### 易混点

- 认证：确认身份。
- 授权：分配权限。
- 审计：记录和追责。

- 可靠性：设备能否正确完成任务。
- 可用性：设备当前是否可以使用。

### 易考选择题

- 信息安全五要素是什么？
- 拒绝服务攻击破坏哪种属性？可用性。
- 非法篡改数据破坏哪种属性？完整性。
- 身份认证与访问控制是什么关系？认证是访问控制的基础。
- 物理隔离、逻辑隔离属于什么？隔离控制法。

## 3. 记忆口诀

### 口诀

**机完可控审，设数内行；认证看身份，授权管行为，审计留痕迹。**

### 解释

- 机完可控审：五大安全要素。
- 设数内行：设备、数据、内容、行为安全。
- 认证、授权、审计：分别解决你是谁、能做什么、做过什么。

## 4. 考试一句话总结

考试最常考信息安全五要素、认证与访问控制的区别，以及泄露、篡改、拒绝服务分别破坏机密性、完整性和可用性。
