# 1. 本节核心思想（100字以内）

基于构件的软件工程（CBSE）是一种**以软件复用为核心**的软件开发方法，通过复用已有构件（购买而不是重新开发），经过适配和组装快速构建系统，提高开发效率、降低成本和维护难度，其核心思想是**复用 + 组装**。

---

# 2. 考试高频考点

- **考点1：CBSE核心思想**
  **购买而不是重新构造（Buy, Don't Build）**，开发重点由"编程"转向"组装"。

- **考点2：构件五大特征（★★★★★）**
  - 可组装性
  - 可部署性
  - 文档化
  - 独立性
  - 标准化

- **考点3：CBSE开发流程（★★★★★）**
  系统需求 → 识别构件 → 修改需求 → 架构设计 → 构件适配 → 构件组装。

- **考点4：三种构件组装方式（★★★★★）**
  - 顺序组装
  - 层次组装
  - 叠加组装

- **考点5：接口不兼容及解决方案**
  不兼容类型：
  - 参数不兼容
  - 操作不兼容
  - 操作不完备

  **解决方法：适配器（Adapter）+ 胶水代码（Glue Code）**

- **易混点**
  **CBSE ≠ 面向对象**
  - 面向对象：强调类、对象设计
  - CBSE：强调已有构件复用与系统组装

- **易考选择题**
  下列哪项不是构件组装的不兼容类型？
  > **答案：数据结构不兼容（教材未列出）**

# 3. 记忆口诀

## 口诀

**五特征，六步骤；三组装，三不兼；适配接口来实现。**

## 解释

- **五特征**
  可组装、可部署、文档化、独立、标准

- **六步骤**
  需求 → 找构件 → 改需求 → 架构 → 适配 → 组装

- **三组装**
  顺序、层次、叠加

- **三不兼**
  参数、操作、操作不完备

- **适配实现**
  使用 Adapter + 胶水代码解决接口问题

## 图2：三种构件组装方式

```text

        构件A
          │

```
