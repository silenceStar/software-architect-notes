架构评估重点：
| 看到题目                   | 想到      |
| ---------------------- | ------- |
| **3秒、5000请求/秒、1000并发** | 🚀 性能   |
| **很少故障、连续运行、故障率**      | 🛠️ 可靠性 |
| **主备、故障切换、99.99%**     | 🟢 可用性  |
| **密码、权限、加密、认证**        | 🔐 安全性  |
| **需求变化、修改模块、2周完成**     | 🔧 可修改性 |
| **能不能正确完成业务功能**        | ⚙️ 功能性  |
| **不同客户、配置、定制、不同版本**    | 🔄 可变性  |
| **接口、第三方系统、数据交换**      | 🔌 互操作性 |
