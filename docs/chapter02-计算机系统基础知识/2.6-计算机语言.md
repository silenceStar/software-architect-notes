# 2.6 计算机语言

## 1. 本节核心思想（100字以内）

计算机语言是人与计算机交换信息的工具，主要包含表达式、流程控制和集合。按用途和抽象程度可分为机器语言、汇编语言、高级语言、建模语言和形式化语言，各类语言在执行效率、可移植性、表达能力和使用场景上各有特点。

> 本节以概念分类和对比为主，不画图也能理解；记忆时可抓住“机器执行、汇编符号、高级编程、UML建模、形式化验证”这条主线。

## 2. 考试高频考点

- **考点1：机器语言、汇编语言和高级语言的区别**  
  机器语言由二进制指令组成，可被CPU直接执行；汇编语言是机器指令的符号化表示，需要汇编程序翻译；高级语言更接近自然语言，易于开发且可移植性较好。

- **考点2：机器指令的组成和地址格式**  
  一条机器指令通常由操作码和地址码组成，按显式地址数量可分为三地址、二地址、单地址和零地址指令，其中零地址指令常见于堆栈型计算机。

- **考点3：汇编语言的三种语句**  
  汇编语言包括指令语句、伪指令语句和宏指令语句；指令语句在运行时由CPU执行，伪指令在汇编时处理且通常不生成机器代码，宏指令是对已定义程序段的引用。

- **考点4：UML的组成与基本关系**  
  UML由基本构造块、图和公用机制组成；基本构造块包括事物和关系，其中四种基本关系是依赖、关联、泛化和实现。

UML：统一面向对象建模语言，统一建模表示方式。
UML 2.0：UML 的重要版本，进一步规范和完善建模体系，图主要分为结构图和行为图。

先记总框架：

6种结构图 + 7种行为图，其中序列、通信、交互概览、计时属于交互图。


UML 顺序图/ 序列图 的 5 种消息：
| 消息类型     | 含义           | 好理解的例子                |
| -------- | ------------ | --------------------- |
| **同步消息** | 发消息后，要等对方处理完 | `A → B：查询()`，A等B返回    |
| **异步消息** | 发出去就不等了      | `A → B：发通知()`，A继续干自己的 |
| **返回消息** | 对方处理完，返回结果   | `B → A：返回查询结果`        |
| **自消息** | 对象向自身发送消息，调用自身的方法	   | `A → A：自己调用自己`        |
| **创建消息** | 创建一个新对象/参与者  | `A → B：create`        |
| **销毁消息** | 销毁一个对象/参与者   | `A → B：destroy`       |

2. 对象图（Object Diagram）

类图描述的是：

“患者这个类长什么样。”

对象图描述的是：

“现在具体有哪些患者对象。”

例如：

patient001:患者
----------------
name = 张三
age = 35

patient002:患者
----------------
name = 李四
age = 42

doctor001:医生
----------------
name = 王医生

注意：

患者

是类；

patient001:患者

是对象。

所以：

类图 = 蓝图
对象图 = 蓝图造出来的具体东西

4. 序列图（Sequence Diagram）

这个非常重要，软考很爱考。

看对象之间按照时间顺序发送消息。

例如“患者预约挂号”：

患者        预约系统        医生排班系统      数据库
 |             |                |              |
 |--预约请求-->|                |              |
 |             |--查询排班----->|              |
 |             |<--返回排班-----|              |
 |             |------------------------------>|
 |             |<-----------保存预约------------|
 |<--预约成功--|                |              |

重点：

从上往下看时间。

所以：

序列图 = 谁先调用谁、谁后调用谁

看到生命线 + 消息 + 时间顺序，就是它。

5. 通信图（Communication Diagram）

它和序列图最容易混。

还是“预约挂号”。

但通信图更强调：

哪些对象之间发生了通信。

例如：

患者
  |
1:预约()
  ↓
预约系统
  |
2:查询排班()
  ↓
排班系统
  |
3:保存预约()
  ↓
数据库

这里通过：

1:
2:
3:

表示消息顺序。

和序列图区别
序列图	通信图
强调时间顺序	强调对象之间的连接/通信
生命线很明显	对象之间的链接很明显
从上往下看	看对象之间怎么联系

一句话：

序列图看“先后”，通信图看“谁和谁说话”。

13. 计时图（Timing Diagram）

这个比较少见，但既然你说13种都要掌握，就一定要认识。

它关注：

对象状态/条件随着时间如何变化。

比如预约状态：

时间 →   10:00     10:05     10:10     10:30

预约状态
        待预约 ───→ 已预约 ───→ 已确认 ───→ 已完成

或者：

服务器状态

运行 ────────────────┐
                     ↓
                    故障
                     ↓
                 恢复运行

它和状态图的区别：

状态图关注“状态怎么转换”。

计时图强调“什么时候发生转换、持续多久”。

所以看到时间轴，优先想到计时图。




- **考点6：形式化语言和Z语言**  
  形式化方法使用具有精确数学语义的语言描述、分析和验证软件系统；Z语言以集合论和一阶谓词逻辑为基础，使用模式描述系统状态和操作。

- **易混点：指令语句与伪指令语句**  
  指令语句汇编后产生机器代码，其操作在程序运行时完成；伪指令通常不产生机器代码，其操作在源程序汇编时完成。

- **易混点：泛化与实现**  
  泛化表示子类继承父类，是“特殊—一般”关系，通常画空心三角实线；实现表示类或构件履行接口规定的契约，通常画空心三角虚线。

- **易混点：UML是语言而不是开发方法**  
  UML是一种与具体编程语言无关的标准建模语言，只规定模型的表示符号和规则，本身不规定完整的软件开发过程。

- **易考选择题：哪种语言能被计算机直接执行？**  
  机器语言可以被CPU直接识别和执行，汇编语言和高级语言都必须经过相应的翻译处理。

- **易考选择题：哪种汇编语句不产生机器代码？**  
  伪指令语句通常不产生机器代码，它主要用于指导汇编程序分配存储空间、定义变量或完成其他汇编工作。

- **易考选择题：UML中表示系统外部可见功能的是哪种图？**  
  用例图从外部使用者角度描述系统提供的功能，适合对系统语境和功能需求进行建模。

- **易考选择题：哪种形式化语言采用“状态—操作”风格？**  
  Z语言采用“状态—操作”风格，以集合论和一阶谓词逻辑作为形式语义基础。

## 3. 记忆口诀

### 口诀

**机汇高，模形全；操地组成指令篇；指伪宏，运汇分；事关图，依关泛实；用逻进实部；Z集谓，状态操作保精确。**

### 解释

- **机汇高，模形全**：计算机语言包括机器语言、汇编语言、高级语言、建模语言和形式化语言。
- **操地组成指令篇**：机器指令由操作码和地址码组成。
- **指伪宏，运汇分**：汇编语句分为指令、伪指令和宏指令；指令在运行时执行，伪指令在汇编时处理。
- **事关图，依关泛实**：UML基本内容包括事物、关系和图；四种关系是依赖、关联、泛化和实现。
- **用逻进实部**：UML五种视图是用例、逻辑、进程、实现和部署视图。
- **Z集谓，状态操作保精确**：Z语言基于集合论和一阶谓词逻辑，通过状态和操作精确描述系统。
