多核技术
│
├── 多核 = 硬件
│   └── 一个处理器集成多个计算内核
│
├── 多线程 = 软件/硬件技术
│   └── 多个线程并发执行
│
├── 并发 Concurrency
│   └── 交替推进
│       └── 单核也可以
│
├── 并行 Parallelism
│   └── 真正同时执行
│       └── 多核才能充分实现
│
├── 多核程序设计
│   ├── 需要程序并行化
│   ├── 合理划分任务
│   ├── 合理分配负载
│   ├── 线程同步/锁
│   └── Cache一致性
│       └── False Sharing
│
└── Redis
    ├── 持久化
    │   ├── RDB → 快照 → BGSAVE
    │   └── AOF → 写命令日志
    │
    └── 主从复制
        ├── 全量复制 → RDB
        └── 增量复制 → 变化部分


| 对比    | RDB              | AOF              |
| ----- | ---------------- | ---------------- |
| 原理    | **定期保存数据快照**     | **记录写操作命令**      |
| 数据完整性 | 两次快照之间可能丢失数据     | 通常数据丢失较少，取决于同步策略 |
| 文件大小  | **较小、紧凑**        | 通常较大             |
| 恢复速度  | **较快**           | 通常较慢，需要重放命令      |
| 对性能影响 | 备份时可能有一定影响，但总体较低 | 写操作需要记录日志，有一定开销  |
| 适合    | 快速备份、快速恢复        | 对数据持久性要求较高       |
