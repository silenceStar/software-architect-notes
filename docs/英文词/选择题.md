1. 软件架构结构（Software Architectural Structures）
英文	中文	考试触发词
Module Structure	模块结构	Code、Data、decomposition
Component-and-Connector Structure	构件与连接件结构	Runtime、Interaction、Communication
Allocation Structure	分配结构	Hardware、Deployment、Development Team
Interface	接口	Contract、Interaction、Boundary
Dependency	依赖	Depends on、Requires
Configuration	配置	Components、Connectors、Arrangement

记忆方法：
- Module：构建什么。
- Component & Connector：运行时如何交互。
- Allocation：软件分配到哪里。
